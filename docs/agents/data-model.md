# Data Model

## Entities

### Link

```
id            BIGINT IDENTITY PK
shortLinkId   VARCHAR (unique)
originalUrl   VARCHAR
createdAt     TIMESTAMP
updatedAt     TIMESTAMP (nullable)
activeFrom    TIMESTAMP (nullable) — null means "active from the beginning"
activeUntil   TIMESTAMP (nullable) — null means "never expires"
description   VARCHAR (nullable)
```

`isActive()` returns true when `now` is within `[activeFrom, activeUntil]`, treating nulls as unbounded. Both null → always active.

Schema generated by Hibernate (`ddl-auto: create-drop`). The `link` and `link_user` tables are commented out of `schema.sql` for this reason.

### LinkUser

```
id           BIGINT IDENTITY PK
shortLinkId  VARCHAR
userName     VARCHAR
```

Join table mapping a link to its owner. Created when an authenticated user creates a link. Deleted in the same transaction when a link is deleted.

### LinkUsage

```
id           BIGINT IDENTITY PK
shortLinkId  VARCHAR
usedAt       TIMESTAMP
```

Append-only usage log. One row per click. Only written for links that have a `LinkUser` row (i.e., only user-owned links are tracked).

Defined in `schema.sql` (not Hibernate) because it needs to be created before the app inserts seed data.

## DTOs

All are Java records with Bean Validation annotations.

### CreateLinkRequestDto

| Field        | Type          | Constraints                    |
|-------------|---------------|-------------------------------|
| url         | String        | @NotBlank, @Size(max=2048), @Pattern(`https?://.*`) |
| description | String        | @Size(max=255)                |
| activeFrom  | LocalDateTime | optional                      |
| activeUntil | LocalDateTime | optional                      |

Used by both anonymous and authenticated controllers. Anonymous path ignores `description`, `activeFrom`, `activeUntil`.

### UpdateLinkRequestDto

| Field       | Type          | Constraints           |
|-------------|---------------|-----------------------|
| originalUrl | String        | same as url above     |
| description | String        | @Size(max=255)        |
| activeFrom  | LocalDateTime | optional              |
| activeUntil | LocalDateTime | optional              |

### LinkCountDto

```java
record LinkCountDto(long totalLinks, long activeLinks, long expiredLinks)
```

## Repositories

### LinkRepository

Key custom queries:

```java
// Native SQL — checks temporal validity
@Query("SELECT * FROM link WHERE short_link_id = :id AND (active_from IS NULL OR active_from <= now()) AND (active_until IS NULL OR active_until >= now())", nativeQuery=true)
Optional<Link> findActiveLinkByShortLinkId(String id);

// JPQL join
@Query("SELECT l FROM Link l JOIN LinkUser lu ON l.shortLinkId = lu.shortLinkId WHERE lu.userName = :username")
@PreAuthorize("authentication.name == #username")
List<Link> findUserLinks(String username);
```

### LinkUserRepository

Notable: overrides `save()` with `@PreAuthorize` to guard at the repository boundary. This is an intentional Spring Security pattern, not dead code.

Custom queries use `@Query` with JPQL or native SQL for active/expired counts (involves joining `Link` on `activeUntil`).

### LinkUsageRepository

Single custom method:
```java
List<LinkUsage> findByShortLinkIdOrderByUsedAtAsc(String shortLinkId);
```

## Database

H2 in-memory, recreated on every startup (`ddl-auto: create-drop`). `schema.sql` and `data.sql` run after Hibernate creates its tables (`defer-datasource-initialization: true`).

`data.sql` seeds:
- 2 users (john, sam) with ROLE_USER
- 5 links (3 for john, 2 for sam), mix of active and expired
- ~41 `link_usage` rows spread across those links
