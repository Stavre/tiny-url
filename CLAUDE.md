# TinyURL — Claude Context

A Spring Boot 4.0.3 URL shortener. Anonymous users create 3-day short links; authenticated users create links with custom dates, descriptions, and usage stats.

## Quick Facts

- **Language:** Java 25
- **Framework:** Spring Boot 4.0.3, Spring Security 7.x, Thymeleaf (no REST API — all HTML views)
- **Database:** H2 in-memory, recreated on each restart, seeded from `schema.sql` + `data.sql`
- **Test users:** john / password, sam / password (both ROLE_USER)
- **Build:** `./gradlew check` runs tests + Checkstyle + PMD + JaCoCo (≥70% line coverage)

## Critical Spring Boot 4.x Gotchas

These will cause hard-to-diagnose failures if forgotten:

1. **`@AutoConfigureMockMvc` package changed:** `org.springframework.boot.webmvc.test.autoconfigure.AutoConfigureMockMvc` (not `boot.test.autoconfigure.web.servlet`)
2. **`@MockBean` replaced by `@MockitoBean`:** `org.springframework.test.context.bean.override.mockito.MockitoBean`
3. **`@WithMockUser` does not work** with `@SpringBootTest + @AutoConfigureMockMvc` — use `.with(user("john").roles("USER"))` inline per request instead
4. **`spring-security-test` is not auto-included** — must add `testImplementation 'org.springframework.security:spring-security-test'` explicitly

## Checkstyle Import Order (Google Style)

Static imports first, then all non-static — `java.*` is in the same non-static group as `org.*` and `com.*`, no blank line before it:

```java
import static org.assertj.core.api.Assertions.assertThat;
import static org.mockito.Mockito.when;

import com.stavre.tinyurl.entity.Link;
import org.junit.jupiter.api.Test;
import java.util.List;   // NO blank line here
```

## Do Not Remove

Two things look like dead code but must stay — user constraint: "remove unused code but do not touch spring security overloads":

- **3-arg `hasPermission(Authentication, Object, String)` in `LinkPermissionsEvaluator`** — always returns false; Spring requires the method on the interface
- **`save(LinkUser)` override in `LinkUserRepository`** — has `@PreAuthorize` guard; required for repository-level security

## Key Files

```
src/main/java/com/stavre/tinyurl/
├── configuration/SecurityFilterChainConfig.java   — URL auth rules, method security, permission handler
├── authorization/LinkPermissionsEvaluator.java    — hasPermission() for link ownership
├── service/AnonymousLinkService.java              — anonymous link creation (Bean, not @Service)
├── service/AuthLinkService.java                   — user link CRUD (Bean, not @Service)
├── factory/LinkFactory.java                       — creates Link entities with short codes
└── util/ShortCodeGenerator.java                   — 6-char alphanumeric codes via SecureRandom

src/main/resources/
├── application.yaml   — H2 config, APP_BASE_URL
├── schema.sql         — link_usage + auth tables (link/link_user generated by Hibernate)
├── data.sql           — seed users, links, usage rows
└── static/css/main.css — full-width layout (overflow-x: hidden on html,body)

pmd/pmd-rules.xml      — custom PMD ruleset (UnitTestShouldIncludeAssert excluded)
config/checkstyle/     — Checkstyle config (Google style)
```
